# NaNLM generative language architecture — evidence-gated plan

## Current verified basis
One physical HW0:0 `Root` is exactly 8,388,608 bytes, with 256 heads,
32,640 mirrored pairs and head 255 reserved for Nannet ingress. Neither
the sparse contextual `.byte-lm` overlay nor the compact `.rnn-lm`
checkpoint duplicates the root. This is a shared logical state with
independent inference circuits and experiment controls. A training job
does not make GitHub Actions persist processes across runs.

1. A source-disjoint synthetic circular-offset test transferred across
   unseen sources only when shared operators were isolated. A matched
   conventional offset estimator achieved the same 100% top-1 result.
2. Variable-order byte context models generate tokens freely by sampling
   their own next-byte distribution, repeatedly feeding the results back
   into the same context.
3. A 32D learned neural recurrent prediction circuit now has an explicit
   eight-step truncated backward signal. Its recurrent model is a
   separate **experimental pathway**, not an established language upgrade.
4. A probability-level hybrid combines the count predictor and recurrent
   predictor without duplicating topology. The mix must be calibrated on
   separate development documents, then held constant on test documents.

## Architectural invariant
**One logical universe, many learning processes; never many unconstrained
minds.** Model components must address one HW0 root, use stable typed
provenance for factual claims, preserve four-valued contradictions, and
never treat the geometry of addresses as proof of language semantics.
Keep the probabilistic word/byte prediction store distinguishable from
the four-valued truth-evidence and timestamped claim store.

## Independent and composable research tracks

### A. Statistical backbone
The order-0 through order-5 interpolated byte predictor provides a
probability-calibrated fallback. Add a held-out calibration splitter
which selects order/smoothing on validation, never on the reported test.
Freeze that selection before any neural/geometric comparison. Detect
count collisions, saturated counts, journal growth, invalid UTF-8
and prefix-boundary contamination. Raise context length only when the
held-out improvement justifies storage and latency.

### B. Neural prediction and sequence memory
The current RNN32 has 32 hidden units and a truncated eight-step
backward window. It is a small recurrent diagnostic, not a modern
decoder language model. Next: gradient clipping, batch updates, separate
optimizer moments and reproducible checkpoint schema, followed by
parameter-matched GRU and 128D attention baselines with 128–512-token
context. Distinguish tests of long-distance agreement, paragraph-level
consistency, and memorization. Do not claim general language ability
from simple rhythmic or repetitive text.

### C. NaN16 geometric transfer
Keep shared SO(3)/U(1) operators and 256 head representations, but
prevent local head updates from erasing a global transferable operator.
Test zero-shot mappings, typed relation composition, order-sensitive
triangle holonomy, inverse constraints, and gauge covariance against
matched non-geometric networks and closed-form controls. Only turn on
geometry in the language prediction circuit if disjoint-document
perplexity and semantic transfer both improve reproducibly.

### D. Semantics, retrieval, and provenance
Use exact WordNet identifiers, lemma/gloss text and relation metadata
as auxiliary supervision, never as a forced next-byte oracle. Separate
surface-form generation from factual claims. Claim paths retain support,
refutation, both and unknown with provenance; avoid turning logical
refutation into a generic negative language example. Retrieval assists
answers, while a trained decoder remains responsible for language.

### E. Tokenization, multilingual text, and generated output
The current 0..254 byte vocabulary treats 255 as a boundary. It is not
a UTF-8-aware human-language tokenizer: a generated byte continuation
may be invalid UTF-8. Add deterministic UTF-8 validation, EOS and
whitespace awareness, a reversible byte fallback and optional learned
subword segmentation. Verify proper handling of multibyte codepoints,
punctuation, newline and prompts that end mid-codepoint. Train on
document-level context rather than resetting every 5 bytes.

### F. Storage and distributed training
The root, numeric pair/phase fields, event journals, `.byte-lm`, and
`.rnn-lm` are different physical representations of ONE state. They
are not jointly crash-atomic. Introduce a generation-id manifest,
write-ahead checkpoint staging, content hashes, bounded compaction,
root generation ownership, and optimistic publication of accepted
updates. GitHub runners act as disposable workers with explicit state
handoff. Do not pretend that Action runner time is persistent cognition.

## Mandatory scientific gates
- Disjoint **documents**, topics, writing styles and time windows.
- Compare uniform, unigram, interpolated n-gram, conventional RNN/GRU,
  shared-geometry and hybrid with matched budgets and compute.
- For each: train/validation/test next-byte nats, bits per byte,
  accuracy, unseen context proportion, and repeated seeds. Prefixes
  must be evaluated with the same scoring alignment.
- Report generated continuations and their length, repetition, entropy,
  UTF-8 validity, distinct n-grams and human-readable coherence.
- Run negative controls: shuffled labels, mismatched contexts,
  duplicate corpus leakage and random frozen embeddings.
- Report throughput, memory, root consistency and crash/restart replay.
- A feature may pass correctness CI while FAILING the quality gate.
  Correctness and generalization are not the same milestone.

## Next pass criterion
A publishable partial engineering milestone is deterministic
free-running native generation with controlled persistence (already
demonstrated on small fixtures). A generalization milestone requires
better held-out document CE than the best tuned count baseline over
multiple independent splits and seeds, with a repeatable improvement
and no test-set hyperparameter selection. A fluent-language milestone
additionally needs real prose corpora and coherent open-ended output.
None of these results implies AGI.
