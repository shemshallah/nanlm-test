# Unified causal model

`train-text`, `eval-text`, `generate`, `explain`, `spectrum`, and `live` use one causal history and one probability distribution. The adaptive mixture combines variable-context counts, a recurrent model, binary-phase/Boolean predictors, geometry, an FFT-derived expert, and exact WordNet retrieval. Every candidate byte maps to the same canonical `address(previous, candidate)` leaf, its mirror, and its physical cell. Byte 255 remains the gateway and resets causal history. FFT bins are a learned byte prior, not a proven semantic mapping.

```
make nanlm
./nanlm /tmp/model import-wordnet tests/fixtures/data.noun
./nanlm /tmp/model train-text corpus.txt 2
./nanlm /tmp/model eval-text heldout.txt
./nanlm /tmp/model generate 'the little ' 200 11
./nanlm /tmp/model explain 'an ' entity
./nanlm /tmp/model live
```

Evaluation and generation do not train the model. Training updates all predictors from the same pre-observation state; pair evidence is recorded once. A manifest checks the root, model overlays and WordNet index together on reload. It detects mixed checkpoints but does not make writes crash-atomic. `adopt-state` deliberately resets mixture weights when adopting changed legacy components. Use backups before adoption.

The SQLite shard learner remains a separate aggregation tool; its counts are not automatically imported into the unified model. WordNet routes still express local intent, with no HW4 network transport. This is an experimental byte model, not evidence of open-domain fluency. Generated bytes can be invalid UTF-8. Preserve document-disjoint evaluation and matched baselines.
